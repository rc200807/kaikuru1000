# 買いクル 画面ドキュメント

買いクル（中古品買取サービス）の全画面（109画面）のドキュメントです。
ポータル別にファイルを分けて管理しています。

## 構成

| ポータル | 対象ユーザー | 画面数 | ドキュメント |
|---|---|---:|---|
| 顧客 | 一般顧客（買取依頼者） | 15 | [customer.md](customer.md) |
| 店舗 | 店舗スタッフ | 22 | [store.md](store.md) |
| 管理 | 本部管理者 | 42 | [admin.md](admin.md) |
| パートナー | セールスパートナー | 9 | [partner.md](partner.md) |
| sysadmin | システム管理者 | 12 | [sysadmin.md](sysadmin.md) |

## 主要URLパターン

| パス接頭辞 | ポータル |
|---|---|
| `/`, `/login`, `/register`, `/mypage`, `/contract-view`, `/estimate-view`, `/inquiry/*`, `/magic/*`, `/f/*`, `/preview/*` | 顧客 |
| `/store/*` | 店舗 |
| `/admin/*` | 管理 |
| `/partner/*` | パートナー |
| `/sysadmin/*` | sysadmin |

## 各ドキュメントの構成

1. ポータルの目次テーブル（# / URL / 画面名）
2. 画面ごとに以下を記載:
   - **画面名**
   - **役割**（誰が何のために使うか）
   - **主要機能**（操作・表示要素の箇条書き）

## 更新方針

- 画面を追加・改修した際は、対応するMDファイルを更新してください
- 大きな機能追加時は目次テーブルにも反映してください
- 役割・機能は実装に忠実に書く（推測ではなく実コード基準）
